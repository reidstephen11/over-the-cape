## Modelling notes (Three.js / WebGL)

1. **Block-out from wheelbase 2285 mm** and width 1665 mm first; resolve length 3840 vs 3870 against your chosen year/market.
2. Signature cues: round sealed-beam headlights, horizontal grille bars, flat fold-down windscreen, short rear overhang relative to FJ45, external spare, slab sides, exposed door hinges on many years.
3. Soft-top vs hardtop changes roof silhouette and rear glass — pick one early.
4. Keep poly budget browser-friendly; use a free Sketchfab FJ40 only if its licence allows your game use, else rebuild from this photo set + SVG guide.
5. Interior: only one free dash photo is in-pack; seats, tunnel levers, and door cards need more Commons finds or link-only museum photos.
6. Underside: one chassis photo (`underside-01.jpg`); leaf packs, axle housings, and transfer case need more refs (IH8MUD / manuals — link-only).
