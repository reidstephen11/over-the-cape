# Modified 80 Series — Sooty MkII-inspired

The owner requested this separate model draft in the game on 27 October 2026.
Its body and wheel source were recovered from the earlier review chat's build
commands, including the final door-surface, board-mount and beadlock revisions.
The instrument housing is moved behind its working dial faces during integration.
This release integrates that draft; the requested photo-based second revision is
still outstanding. No new exterior shape is claimed to have been photographically
verified, and no reference photograph is redistributed here.

## Sources

- [Repco's Sooty MkII rundown](https://www.repco.com.au/know-how/ex31-sooty-mkii-4wd-rig-rundown):
  the rebuilt 1HD-T engine and the exterior equipment/finish used for the study.
- [Toyota's 80 Series history](https://www.toyota-global.com/company/history_of_toyota/75years/vehicle_lineage/car/id60013935/index.html):
  generation and nominal 2,850 mm wheelbase.
- [Brown Davis' 80 Series tank application](https://www.browndavis.com.au/toyota-landcruiser-80-series-168-litre-45-gallon-long-range-fuel-tanks/):
  Australian factory 95 L main and 50 L auxiliary tanks. The game uses this
  145 L configuration, without asserting the actual modified Sooty's tank fitment.

## Dimensions and setup

| Item                            | In the integrated draft                                              |
| ------------------------------- | -------------------------------------------------------------------- |
| Axle spacing                    | 2.850 m                                                              |
| Wheel-centre track              | 1.670 m, modified                                                    |
| Tyres                           | 0.889 m diameter, 0.315 m width (nominal 35 inch)                    |
| Body skin length                | 4.700 m, from z = -2.230 to +2.470; barwork and spare extend further |
| Nominal upper-body half width   | 0.925 m; lower-door crown and fittings extend further                |
| Parked hub height in body frame | -0.196 m                                                             |
| Snorkel opening                 | x = 1.002, y = 1.418, z = -0.651; nominal 2.0585 m above the ground  |
| Tank                            | 145 L; episodes currently start with 50 L                            |

The body width and silhouette remain review targets. The nominal skin width is
narrower than the wide-body factory 80's commonly listed 1.93 m; this integration
preserves the draft instead of reshaping it without the photographs. Loaded mass
(2,800 kg), tuned engine torque (500 Nm), axle gearing (4.3) and consumption are
game estimates. The five-speed/2.488 transfer setup represents a modified 80;
it is not claimed as an exact measurement of Shaun Whale's drivetrain.

The draft displays one rear spare. The episode's spare-wheel supply remains its
existing value, as it does for recovery-board supplies. Four roof boards are
grouped into the two deployable board units used by the game.

## Inspection

Use `/scripts/studio/?vehicle=sooty80` with the dev server. Front-left, side, rear
and cockpit renders were inspected during integration. No external reference
images could be inspected in this environment. The outstanding visual comparison
must precede any future body reshaping.
